# 03 — User Flows

**Student:** Login → Dashboard → Course list (enrolled only) → Course detail → open lesson → mark complete → progress % updates → Tugas → open task → submit (file / isian / pilihan ganda) → score (PG scored by server) → Hasil Belajar → Pembayaran → pay → *Menunggu Verifikasi* → admin confirms → *Lunas*.

**Tutor:** Login → Dashboard → Kelas / Jadwal → Materi & Modul → Tugas: create → view submissions → grade → Presensi: set status, save → Siswa / Nilai / Perlu Perhatian follow-up → Bank Soal CRUD → Pengumuman create → Pesan reply.

**Admin:** Login → Dashboard → Siswa CRUD → Pendaftaran: verify / accept / reject → Tutor & staff CRUD → Program / kelas / rombel / ruang CRUD → Jadwal: create (clash rejected) → SPP: record payment → Pembayaran verify → Piutang confirm → Pengeluaran / Honor → Pengaturan lembaga.

**Guest:** Landing → Login / Register (student) → Forgot password → reset link → new password.
