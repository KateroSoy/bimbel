# Future Scope

These features are explicitly excluded from the current "Web Based Lite" implementation. Do NOT build them during this phase.

- Native Mobile App (Android APK, iOS, React Native, Flutter)
- Audio/Video recording in browser
- Advanced finance (Accounting, Ledgers, Tutor Payroll, Profit/Loss)
- Advanced reporting (Custom report builder, complex Excel exports, BI dashboards)
- Student Attention algorithm (Automatic at-risk detection)
- Audit log & Advanced Workflow (Custom BPM, enterprise audit)
- WhatsApp API integration (unless a simple stub/link already exists)
- Payment Gateway integration
- AI teaching assistant / AI Grading
- Google Classroom / Google Calendar integration
- Complex CBT (Computer Based Test) module outside of simple quiz assignments
