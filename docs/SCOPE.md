# Scope: LearnSpace+ Web Based Lite

## Included
1. **Public Website**: Landing, Programs, About, Login entry. Responsive.
2. **Login**: Unified login routing to role-specific portals.
3. **Admin Lite**: Basic dashboard, Program/Class/Student/Tutor CRUD, Material/Task management, Basic settings.
4. **Tutor Lite**: Dashboard, Assigned classes, Materials, Task creation/grading, Submission status.
5. **Student Lite**: Dashboard, Schedule, Courses/Materials, Task viewing & submission, Grades.
6. **Responsive Web**: Must work flawlessly on Desktop, Tablet, and Mobile browsers.
7. **Branding**: "LearnSpace+ by StudyHack".

## Excluded (Future Scope)
- Native Mobile App (APK/iOS).
- Advanced Analytics/BI.
- Complex Finance (Accounting, Payroll).
- Advanced Assignments (Audio/Video, AI grading).
- External API (WhatsApp, Google integrations) unless trivially supported already.
- Complex Workflows/Audit logs.
