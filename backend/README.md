# LearnSpace+ API

Laravel 12 API for the LearnSpace+ SPA. Setup, tests and deployment are described in the repository root `README.md` and `DEPLOY_HOSTINGER.md`.

- Resources (tables, validation, access): `config/resources.php`
- Business rules: `app/Support/ResourceHooks.php`
- Routes: `routes/api.php`
- Tests: `tests/Feature`
